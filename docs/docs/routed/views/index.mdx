# Views & Templates

Routed exposes a pluggable view engine API. The built-in Liquid engine renders
HTML templates while `ViewEngine` lets applications integrate another
renderer.

`ViewServiceProvider` owns a typed `RoutedViewConfig`. If templates should use
a named storage disk, register `RoutedStorageProvider` before it:

```dart
import 'package:routed/routed.dart';

final engine = await Engine.create(
  providers: [
    ...Engine.defaultProviders,
    RoutedStorageProvider(
      configuration: StorageConfig(
        defaultDisk: 'resources',
        disks: {
          'resources': const LocalStorageDiskConfig(root: 'resources'),
        },
      ),
    ),
    ViewServiceProvider(
      RoutedViewConfig(
        engine: 'liquid',
        directory: 'views',
        disk: 'resources',
      ),
    ),
  ],
);
```

See [Liquid templates](/docs/routed/views/templates) for rendering and
extension examples. Provider configuration is fixed for the lifetime of an
engine and validated before boot.
