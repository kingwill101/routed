# Uploads

Routed handles file uploads through multipart form parsing. Limits are applied
while the request is streamed, so an oversized or disallowed upload can be
rejected before it consumes the rest of the request body.

## Configure the provider

Upload settings are typed Dart values. Register `UploadsServiceProvider` with
the `MultipartConfig` for the application:

```dart
import 'package:routed_core/routed_core.dart';

final engine = await Engine.create(
  providers: [
    ...Engine.defaultProviders,
    UploadsServiceProvider(
      MultipartConfig(
        maxMemory: 16 * 1024 * 1024,
        maxFileSize: 5 * 1024 * 1024,
        maxDiskUsage: 16 * 1024 * 1024,
        allowedExtensions: {'jpg', 'png', 'webp'},
        uploadDirectory: 'storage/uploads',
        filePermissions: 0x1a0,
      ),
    ),
  ],
);
```

`allowedExtensions` uses lowercase names without a leading dot. The provider
validates limits, directory, permissions, and extensions before boot.

## Handling uploads

```dart
engine.post('/avatar', (ctx) async {
  final file = ctx.formFile('avatar');
  if (file == null) {
    return ctx.json({'error': 'No file uploaded'}, statusCode: 400);
  }

  await ctx.saveUploadedFile(file, 'storage/uploads/${file.filename}');
  return ctx.json({'saved': file.filename});
});
```

For forms containing multiple files, parse the multipart form once:

```dart
engine.post('/gallery', (ctx) async {
  final form = await ctx.multipartForm();
  for (final file in form.files) {
    await ctx.saveUploadedFile(file, 'storage/uploads/${file.filename}');
  }
  return ctx.json({'uploaded': form.files.length});
});
```

The `MultipartFormMethods` extension also provides `postForm`,
`postFormArray`, `postFormMap`, and `form` for regular multipart fields.

## Enforcement

- `maxFileSize` limits each individual file.
- `maxDiskUsage` limits the total bytes written for files in one request.
- `allowedExtensions` rejects files whose extension is not allow-listed.
- `uploadDirectory` controls where temporary upload files are written.
- `filePermissions` controls permissions applied to uploaded files.

When parsing fails or a limit is exceeded, partial files created for that
request are cleaned up. Applications should still validate MIME types and file
contents when accepting files from untrusted clients.

## Validation

The validation package can apply file-specific rules in a handler:

```dart
await ctx.validate({
  'document': 'file|max_file_size:5242880',
  'image': 'file|allowed_mime_types:image/jpeg,image/png',
});
```

The main upload exceptions are `FileTooLargeException`,
`FileExtensionNotAllowedException`, and `FileQuotaExceededException`.
