# Storage

Storage disks provide the shared file abstraction for uploads, views, and
declarative static mounts. The `routed_storage` package owns both the storage
provider and the `static.mounts` provider.

## Configuration

```yaml title="config/storage.yaml"
storage:
  default: local
  # Base used by storage helpers (cache/session/storage_path).
  base: "{{ env.APP_ROOT }}/storage"
  # Root used for the default local disk when not overridden.
  root: storage/app
  disks:
    local:
      driver: local
      root: storage/app
    assets:
      driver: local
      root: public
    backups:
      driver: local
      root: storage/backups
```

## Driver options

- **Local**: `root`, optional `file_system` (programmatic only).
- Cloud drivers are not created by `RoutedStorageProvider` in this package;
  register a compatible `StorageDisk` implementation when you need remote
  storage.

`storage.root` seeds the default local disk when no explicit disk root is
provided. The provider does not expose a separate `StorageDefaults` service;
use `StorageManager.resolve` for disk paths.

## StorageManager usage

```dart
final storage = await engine.make<StorageManager>();
final logoPath = storage.resolve('logo.png', disk: 'assets');
```
