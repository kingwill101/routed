# Contracts

Routed keeps framework contracts small and typed. Provider configuration is an
immutable Dart object, while host-specific values are supplied through
`RuntimeContext`.

## Typed configuration

Configuration objects that need validation implement
`ValidatableConfiguration`. A provider exposes its object with
`ProvidesTypedConfiguration<T>`:

```dart
class SearchConfig implements ValidatableConfiguration {
  const SearchConfig({this.endpoint = 'http://localhost:9200'});

  final String endpoint;

  @override
  void validate(ConfigValidationContext context) {
    context.require(endpoint.startsWith('http'), 'endpoint', 'must be a URL');
  }
}

class SearchProvider extends ServiceProvider
    with ProvidesTypedConfiguration<SearchConfig> {
  SearchProvider(this.configuration);

  @override
  final SearchConfig configuration;

  @override
  void register(Container container) {}
}
```

Register the provider and read the same value by type:

```dart
final engine = await Engine.create(
  providers: [
    ...Engine.defaultProviders,
    SearchProvider(const SearchConfig()),
  ],
);

engine.get('/search-info', (ctx) {
  final search = ctx.config<SearchConfig>();
  return ctx.json({'endpoint': search.endpoint});
});
```

Duplicate configuration types and invalid values fail before provider boot.
There is no dot-notation map or mutable global configuration contract.

## Cache contracts

Cache storage contracts live in the framework-agnostic server packages. A
`Store` is the low-level backend; a `Repository` adds higher-level operations
such as TTLs, `remember`, and `increment`:

```dart
abstract class Repository {
  FutureOr<dynamic> get(String key);
  FutureOr<bool> put(String key, dynamic value, [Duration? ttl]);
  FutureOr<bool> forget(String key);
  FutureOr<dynamic> increment(String key, [dynamic value = 1]);
  Store getStore();
}
```

Use `routed_cache` to bind a repository or store to a Routed engine. The cache
manager and its driver registry are owned by that adapter package; they are not
part of `routed_core`:

```dart
final engine = await Engine.create(
  providers: [
    ...Engine.defaultProviders,
    RoutedCacheProvider(CacheConfig(store: ArrayStore())),
  ],
);
```

For a custom manager or repository, use the adapter-owned `withCacheManager`
engine option from `package:routed_cache/routed_cache.dart`.

## Runtime input

Use `RuntimeContext` for deployment environment values, secrets, and typed host
bindings. Keep those values separate from portable provider configuration:

```dart
final runtime = RuntimeContext(
  environment: RuntimeEnvironment({'APP_ENV': 'production'}),
  secrets: RuntimeSecrets({'SEARCH_TOKEN': tokenFromPlatform}),
);
```
