# Localization

Routed’s localization provider loads translations from files, resolves a
request locale, and exposes translation helpers. Translation files are
application data; provider startup settings are typed Dart configuration.

## Translation files

Translations live under `resources/lang`. JSON dictionaries are portable and
easy to validate in tooling; nested YAML translation files are also supported
as translation data when your deployment already uses them.

```text
resources/
  lang/
    en.json
    fr.json
```

```json title="resources/lang/en.json"
{
  "greeting": "Hello :name",
  "notifications": {
    "count": "No notifications|{1} One notification|[2,*] :count notifications"
  }
}
```

## Configure the provider

```dart
import 'package:routed/routed.dart';

final engine = await Engine.create(
  providers: [
    ...Engine.defaultProviders,
    LocalizationServiceProvider(
      LocalizationConfig(
        paths: ['resources/lang'],
        resolvers: [
          QueryLocaleResolver(parameter: 'lang'),
          CookieLocaleResolver(cookieName: 'locale'),
          HeaderLocaleResolver(headerName: 'Accept-Language'),
        ],
        defaultLocale: 'en',
        fallbackLocale: 'en',
      ),
    ),
  ],
);
```

Resolver order is explicit. Built-in resolvers include query, cookie, session,
and header; session resolution requires a registered sessions provider. When
`resolvers` is omitted, the provider constructs that default chain.

## Custom resolvers

Construct custom resolvers directly alongside the built-in resolvers:

```dart
final localization = LocalizationConfig(
  resolvers: [
    GeoIpLocaleResolver(geoIpService),
    HeaderLocaleResolver(),
  ],
);
```

## Render translations

```dart
engine.get('/welcome', (ctx) {
  return ctx.json({
    'message': trans('greeting', replacements: {'name': 'Routed'}),
    'locale': currentLocale(),
  });
});
```

Liquid templates can use the `trans` and `transChoice` filters. Validation
messages can be placed in the same locale directories and are selected by the
active translator.
