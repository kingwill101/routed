# Proxy Support

Routed can forward requests to another HTTP server and can normalize client IP
information when the application runs behind a trusted proxy.

## Forward a request

```dart
engine.get('/proxy', (ctx) async {
  return ctx.forward(
    'https://api.example.com${ctx.request.path}',
    options: const ProxyOptions(
      forwardHeaders: true,
      addProxyHeaders: true,
    ),
  );
});
```

Use `ProxyOptions.headers` to add explicitly selected headers. Filter cookies,
authorization headers, and other credentials unless the upstream is trusted to
receive them. The proxy helper adds `X-Forwarded-For`, `X-Forwarded-Host`, and
`X-Forwarded-Proto`.

## Configure trusted proxies

Trusted-proxy and IP-filter settings belong to the typed security provider:

```dart
import 'package:routed/routed.dart';

final security = RoutedSecurityConfig(
  trustedProxies: TrustedProxyConfig(
    enabled: true,
    forwardClientIp: true,
    proxies: ['10.0.0.0/8'],
    headers: ['X-Forwarded-For', 'X-Real-IP'],
    platformHeader: 'CF-Connecting-IP',
  ),
  ipFilter: IpFilterConfig(
    enabled: true,
    defaultAction: IpFilterAction.deny,
    allow: ['10.10.0.0/16', '203.0.113.5'],
    deny: ['0.0.0.0/0'],
    respectTrustedProxies: true,
  ),
);

final engine = await Engine.create(
  providers: [
    ...Engine.defaultProviders,
    RoutedSecurityProvider(security),
  ],
);
```

Only list networks that are actually controlled by your proxy infrastructure.
Trusting every forwarded address lets a client forge its source IP. When the
filter is enabled, deny rules take precedence and rejected requests receive a
`403 Forbidden` before the route handler runs.

Proxy support is rejected during engine validation unless `proxies` contains at
least one explicit network. This prevents a missing configuration from silently
turning forwarded headers into trusted client identity.

## Forward selected headers

```dart
engine.all('/*', (ctx) async {
  return ctx.forward(
    'https://backend.example.com${ctx.request.path}',
    options: ProxyOptions(
      forwardHeaders: false,
      headers: {
        'X-Real-IP': ctx.request.clientIP,
        'X-Forwarded-Proto': ctx.request.scheme,
        'X-Forwarded-Host': ctx.request.host,
      },
    ),
  );
});
```

Never forward hop-by-hop headers such as `Connection`, `Transfer-Encoding`,
`Upgrade`, or proxy authentication headers. Set timeouts and upstream failure
handling at the edge or in the HTTP client layer used for production gateways.
