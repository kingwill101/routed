# Securing file uploads

Treat every uploaded filename, MIME type, and byte as untrusted. Configure the
uploads provider with the smallest useful allow-list and enforce size limits
before accepting the file into application storage.

## Use a strict typed configuration

```dart
import 'package:routed_core/routed_core.dart';

final uploads = MultipartConfig(
  maxMemory: 16 * 1024 * 1024,
  maxFileSize: 5 * 1024 * 1024,
  maxDiskUsage: 6 * 1024 * 1024,
  allowedExtensions: {'jpg', 'png', 'pdf'},
  uploadDirectory: 'storage/uploads',
  filePermissions: 0x1a0,
);

final engine = await Engine.create(
  providers: [
    ...Engine.defaultProviders,
    UploadsServiceProvider(uploads),
  ],
);
```

Configuration validation happens before provider boot. Extensions are
lowercase and omit the leading dot; the framework normalizes their casing but
does not treat an extension allow-list as content validation.

## Limit resource consumption

`maxFileSize` bounds one multipart file. `maxDiskUsage` bounds all files in a
single request, while `maxMemory` limits buffering for multipart parsing. If a
limit is reached, the parser stops and removes partial files from that
request.

Keep `uploadDirectory` separate from any directory served by the static-file
provider. After business validation and optional malware scanning, move or
copy accepted files into the application’s durable storage policy.

## Validate file content

Use application validation in addition to the extension allow-list:

```dart
engine.post('/documents', (ctx) async {
  await ctx.validate({
    'document': 'file|max_file_size:5242880',
    'image': 'file|allowed_mime_types:image/jpeg,image/png',
  });

  final document = ctx.formFile('document');
  if (document == null) {
    return ctx.json({'error': 'document is required'}, statusCode: 422);
  }

  await ctx.saveUploadedFile(
    document,
    'storage/uploads/${document.filename}',
  );
  return ctx.json({'ok': true});
});
```

Do not use the client-provided MIME type as the only security decision. Where
the file type matters, inspect its bytes or pass it through a trusted scanning
service before publishing it.

## Operational checklist

- Keep upload directories outside static mounts.
- Use the smallest practical extension and MIME allow-lists.
- Set both per-file and per-request disk limits.
- Treat `filename` as display data; never concatenate an untrusted path into a
  filesystem operation.
- Handle `FileTooLargeException`, `FileExtensionNotAllowedException`, and
  `FileQuotaExceededException` as client errors without returning internal
  filesystem details.
