# Caching

`routed_cache` adapts `server_cache` to `EngineContext`. Cache configuration is
typed, while the cache manager is an application-owned service:

```dart
import 'package:routed/routed.dart';
import 'package:server_cache/server_cache.dart';

final manager = DataCacheManager()
  ..registerStore('array', ArrayStore());

final engine = await Engine.create(
  providers: [
    ...Engine.defaultProviders,
    RoutedCacheProvider(CacheConfig(store: ArrayStore())),
  ],
  options: [withCacheManager(manager)],
);
```

`withCacheManager` is exported by `routed_cache`, not `routed_core`. This keeps
the core engine independent of cache implementations.

## Operations

```dart
engine.get('/data', (ctx) async {
  final cached = await ctx.getCache('data');
  if (cached != null) return ctx.json({'data': cached, 'cached': true});

  final value = await expensiveOperation();
  await ctx.cache('data', value, 60);
  return ctx.json({'data': value, 'cached': false});
});

await ctx.cacheForever('permanent', value);
await ctx.removeCache('data');
await ctx.incrementCache('visits');
await ctx.decrementCache('stock');
await ctx.rememberCache('stats', 300, computeStats);
await ctx.rememberCacheForever('app-config', loadAppConfig);
```

Select a registered store with `store: 'redis'` on the cache methods. Built-in
`server_cache` stores include array, file, null, and redis. Register concrete
stores directly, or use `DataCacheManager.registerStoreFactory` with a typed
store configuration when construction should be reusable:

```dart
final manager = DataCacheManager()
  ..registerStoreFactory(
    'redis',
    RedisStoreFactory(),
    const RedisStoreConfiguration(host: '127.0.0.1', port: 6379),
  );
```

If a handler needs the lower-level store contract, add the middleware using the
same typed store supplied to `CacheConfig`:

```dart
final store = ArrayStore();
final engine = await Engine.create(
  providers: [
    ...Engine.defaultProviders,
    RoutedCacheProvider(CacheConfig(store: store)),
  ],
  middlewares: [cacheMiddleware(store)],
);
```

The provider publishes `CacheConfig` and `Store` through the engine container;
the manager remains an explicitly wired service.
