# Session Management

Create a `SessionConfig`, pass it to `RoutedSessionsProvider`, and install
`sessionMiddleware` explicitly:

```dart
import 'package:routed/routed.dart';

final sessionConfig = SessionConfig.cookie(
  appKey: runtime.secrets.requiredString('SESSION_KEY'),
  cookieName: 'routed_session',
  maxAge: const Duration(hours: 1),
  options: SessionOptions(
    path: '/',
    secure: true,
    httpOnly: true,
    sameSite: SameSite.lax,
  ),
);

final engine = await Engine.create(
  providers: [
    ...Engine.defaultProviders,
    RoutedSessionsProvider(sessionConfig),
  ],
  middlewares: [sessionMiddleware()],
);
```

For file-backed sessions, use `SessionConfig.file` with an application-owned
filesystem and storage path. The provider validates the store and cookie
invariants before boot.

## Session operations

```dart
engine.get('/profile', (ctx) {
  final userId = ctx.getSession<String>('user_id');
  ctx.setSession('last_visit', DateTime.now().toIso8601String());

  return ctx.json({
    'user_id': userId,
    'session_id': ctx.sessionId,
    'values': ctx.sessionData,
  });
});

ctx.removeSession('temporary');
ctx.clearSession();
ctx.flash('Profile updated', 'success');
final messages = ctx.getFlashMessages(withCategories: true);
```

The session middleware reads the typed `SessionConfig` and `SessionStore` from
the container. Session setup is explicit and typed; there is no string-based
session configuration surface.

Keep encryption/signing keys in `RuntimeSecrets`; never commit them to source
or include them in configuration error messages. Cookie settings such as
`secure`, `httpOnly`, `sameSite`, and `partitioned` are ordinary typed
`SessionConfig` fields.
