# Typed configuration demo

The `examples/config_demo/` application shows the current configuration model:
`MailConfig` is owned by `MailProvider`, validated before boot, and available
through the typed configuration store.

## Run it

```sh
cd examples/config_demo
dart pub get
dart run bin/server.dart
```

Visit `http://127.0.0.1:8080/` for the service view or
`http://127.0.0.1:8080/configuration` for the typed lookup view.

## Provider-owned configuration

```dart
final engine = await Engine.create(
  providers: [
    ...Engine.defaultProviders,
    MailProvider(
      const MailConfig(
        host: 'mail.example.test',
        port: 2525,
        from: 'demo@example.test',
      ),
    ),
  ],
);

engine.get('/configuration', (ctx) {
  final mail = ctx.config<MailConfig>();
  return ctx.json({'host': mail.host, 'port': mail.port});
});
```

Invalid values fail during `ConfigStore` validation, before provider boot. The
example test demonstrates this with an invalid port. There are no YAML files,
generated config snapshots, or dot-notation lookups in this example.
